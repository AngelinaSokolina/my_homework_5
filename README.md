# Проект: Банковские операции (обработка данных)

## Описание
Этот проект предназначен для фильтрации и сортировки банковских транзакций. 
Он содержит инструменты для маскировки номеров карт/счетов, а также функции для обработки списков данных по их статусу и дате.

## Состав модулей
*   `src/processing.py` — функции фильтрации и сортировки данных.
*   `src/masks.py` — функции маскировки номеров банковских карт и счетов.
*   `src/widget.py` — дополнительные инструменты для обработки дат и типов карт.

## Использование
**Фильтрация по статусу**
Функция `filter_by_state` возвращает список словарей с заданным статусом (по умолчанию EXECUTED):
```
from src.processing import filter_by_state

data = [
    {'id': 1, 'state': 'EXECUTED', 'date': '2019-07-03'},
    {'id': 2, 'state': 'CANCELED', 'date': '2018-06-30'}
]
result = filter_by_state(data, 'EXECUTED')
```

**Сортировка по дате**

Функция `sort_by_date` сортирует данные по дате (по умолчанию от новых к старым):
```
from src.processing import sort_by_date

result = sort_by_date(data, reverse=True)
```

**Модуль decorators**

Модуль содержит универсальный декоратор `@log` для автоматического логирования работы функций. 

Основные возможности:
* Гибкое логирование. 

Выбор между выводом в консоль и записью в текстовый файл.
* Подробные отчеты об ошибках. 

В случае сбоя декоратор записывает имя функции, тип ошибки и входные параметры `(args, kwargs)`, после чего повторно выбрасывает исключение `(raise)`.
* Сохранение метаданных.

Использование `@wraps` гарантирует, что исходное имя функции и её документация сохранятся после декорирования.

***Использование***
```
#Логирование в консоль (по умолчанию):

@log()
def my_function(x, y):
    return x + y
```
```
#Логирование в файл:

@log(filename="mylog.txt")
def my_function(x, y):
    return x + y
```
***Примеры записей в логе***

Успех: `my_function ok`

Ошибка: `my_function error: ZeroDivisionError. Inputs: (1, 0), {}`

## Функции с API
**Модуль utils**

Функция принимает путь до JSON-файла и возвращает список словарей с данными о финансовых транзакциях.

Логика работы:
* Проверяет существование файла по указанному пути
* Пытается открыть и прочитать JSON-файл
* Проверяет, что прочитанные данные являются списком
* Возвращает список транзакций или пустой список в случаях:
   - Файл не существует
   - Файл пустой
   - Файл содержит не список (например, словарь)
   - Файл поврежден (невалидный JSON)
   - 
***Параметры:***

`path` (str | Path): путь к JSON-файлу

***Возвращаемое значение:***

`list`: список словарей с транзакциями. В случае ошибки возвращает пустой список.

**Модуль external_api**

Функция принимает транзакцию и возвращает сумму в рублях. Если валюта не RUB, происходит обращение к внешнему API для конвертации.

Логика работы:
* Извлекает из транзакции сумму и код валюты 
* Если валюта RUB — сразу возвращает сумму 
* Если любая другая валюта — обращается к Exchange Rates Data API 
* При успешном ответе API возвращает сконвертированную сумму 
* При ошибках API (нет соединения, HTTP ошибка, таймаут) возвращает исходную сумму

***Параметры:***

`transaction` (dict): словарь с данными о транзакции

**Возвращаемое значение:**

`float`: сумма в рублях

***Поддерживаемые валюты:*** 

любые валюты, поддерживаемые API

**Переменные окружения**

Для работы функции конвертации валют требуется API ключ. Создайте файл `.env` в корне проекта:

```API_KEY=your_api_key_here```

Шаблон для `.env` файла находится в корневой папке под названием `.env_example`

### Модуль `main.py`

Главный модуль программы, объединяющий весь функционал. Обеспечивает интерактивное взаимодействие с пользователем через консоль.

**load_transactions(file_type)**

Загружает транзакции в зависимости от выбора пользователя.

***Параметры:***

`file_type (int):` 1 — JSON, 2 — CSV, 3 — XLSX

***Возвращаемое значение:***

`list[dict] | None`: список транзакций или None при ошибке

**filter_by_status(transactions)**

Фильтрует транзакции по статусу. Пользователь вводит статус (EXECUTED, CANCELED, PENDING). При неверном вводе запрашивается повторно. Регистр не имеет значения.

***Параметры:***

`transactions (list[dict]):` список словарей с транзакциями

***Возвращаемое значение:***

`list[dict]:` отфильтрованный список транзакций

**format_date(date_str)**

Преобразует дату из любого формата в единый формат `DD.MM.YYYY`.

***Параметры:***

`date_str (str):` строка с датой

***Возвращаемое значение:***

`str`: дата в формате `DD.MM.YYYY` или `"Дата не указана"`

**ask_sort(transactions)**

Спрашивает пользователя о необходимости сортировки по дате. При положительном ответе запрашивает направление сортировки (по возрастанию/убыванию).

***Параметры:***

`transactions (list[dict]):` список словарей с транзакциями

***Возвращаемое значение:***

`list[dict]`: отсортированный или исходный список

**ask_ruble_only(transactions)**

Спрашивает пользователя, нужно ли оставить только рублёвые транзакции.

***Параметры:***

`transactions (list[dict]):` список словарей с транзакциями

***Возвращаемое значение:***

`list[dict]`: отфильтрованный или исходный список

**ask_filter_by_description(transactions)**

Спрашивает пользователя о фильтрации по ключевому слову в описании. При отсутствии результатов предлагает повторить поиск или отменить фильтрацию.

***Параметры:***

`transactions (list[dict]):` список словарей с транзакциями

***Возвращаемое значение:***

`list[dict]`: отфильтрованный или исходный список

**mask_card_number(card_str)**

Маскирует номер карты или счёта, оставляя видимыми только последние 4 цифры.

***Параметры:***

`card_str (str):` строка с номером карты/счёта

***Возвращаемое значение:***

`str`: замаскированный номер или `"Номер карты не найден"`

**display_transactions(transactions)**

Выводит транзакции в красиво отформатированном виде с датой, описанием, отправителем/получателем, суммой и валютой.

***Параметры:***

`transactions (list[dict]):` список словарей с транзакциями

***Возвращаемое значение:***

`None`

**main()**

Главная функция программы. Реализует полный цикл работы:

1. Приветствие и выбор источника данных (JSON/CSV/XLSX)
2. Загрузка транзакций
3. Фильтрация по статусу
4. Сортировка по дате (опционально)
5. Фильтрация рублёвых транзакций (опционально)
6. Фильтрация по слову в описании (опционально)
7. Вывод результатов
